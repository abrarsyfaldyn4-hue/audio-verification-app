# audio_verification_app

تطبيق موبايل حديث يراعي تسلسل مراحل التحقق والتسجيل المطلوبة:

1. إدخال عنوان IP
2. التحقق من صحة صيغة IP
3. إدخال كود التحقق
4. التحقق من الكود
5. طلب صلاحية تسجيل الصوت
6. السماح بالتسجيل
7. تسجيل الصوت
8. إيقاف التسجيل
9. مراجعة الملف
10. إرسال الملف الصوتي
11. النجاح النهائي مع واجهة زرقاء

## التشغيل

```bash
flutter pub get
flutter run
```

## التفاصيل

- تم تصميم التطبيق باستخدام Flutter.
- تدفق الشاشة يعتمد على حالات واضحة ولا يسمح بالانتقال إلا بعد نجاح المرحلة الحالية.
- كل مرحلة مجهزة برسالة حالة واضحة.
- تم تطبيق ألوان مميزة لكل حالة: انتظار، تحقق، تسجيل، نجاح.
