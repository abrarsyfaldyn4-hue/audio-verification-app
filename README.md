# audio_verification_app

تطبيق موبايل حديث يراعي تسلسل مراحل التحقق والتسجيل المطلوبة:

1. إدخال عنوان IP
2. إدخال كود التحقق
3. التحقق من الكود
4. طلب صلاحية تسجيل الصوت
5. السماح بالتسجيل
6. تسجيل الصوت
7. إيقاف التسجيل
8. إرسال الصوت
9. نجاح الإرسال + واجهة زرقاء نهائية

## التشغيل

```bash
flutter pub get
flutter run
```

## ملاحظات

- تم تصميم التطبيق باستخدام `Flutter`.
- تدفق الشاشة يعتمد على حالات واضحة ولا يسمح بالانتقال إلا بعد نجاح المرحلة الحالية.
- يحتوي التطبيق على واجهات للمرحلة الأولى حتى المرحلة النهائية وفق متطلبات التصميم الواردة.
